# ADR 0012: Hospedagem (proposta, aguardando decisão)

* **Status:** aceita quanto às imagens Docker; provedor em aberto
* **Data:** 03/10/2026

## Contexto

Existe uma branch `heroku` antiga. O Heroku não tem mais plano gratuito.

## Decisão

Entregar imagens Docker multi arquitetura (API com worker e site) e um `compose.production.yaml`. Opções a decidir com o dono: VPS barata (Hetzner ou similar) com Caddy e backups; Oracle Cloud Always Free; Render ou Railway. Banco gerenciado ou no próprio servidor com backup externo. Domínio próprio (ex.: refrigeracaocastro.com.br) com API em `api.` do mesmo domínio.

## Consequências

A decisão afeta custo mensal e quem opera o servidor. Nada no código depende do provedor.

## Alternativas consideradas

Manter Heroku (pago).

## Revisão de 05/10/2026

Decidido em parte. As imagens Docker (`infra/docker/api.Dockerfile`, com o worker, e `infra/docker/web.Dockerfile`) e o `infra/compose.production.yaml` com PostgreSQL e Caddy (HTTPS automático e compressão) foram entregues. A API ficou no mesmo domínio do site, no caminho `/api`, em vez do subdomínio `api.`: menos certificados e cookies no mesmo site. O provedor continua em aberto. Operação em `docs/OPERACAO.md`.
