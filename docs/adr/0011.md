# ADR 0011: Padrões REST da API

* **Status:** aceita
* **Data:** 03/10/2026

## Contexto

O protótipo mistura corpo em `DELETE`, `GET` com corpo, estados livres em `PATCH` e códigos de estado inconsistentes.

## Decisão

Convenções de `docs/API.md`: `/api/v1`, recursos no plural, ações de estado como sub recursos, JSON Merge Patch, RFC 9457 para erros, paginação e filtros padronizados, `ETag` e `If-Match` em recursos editados por várias pessoas, `Idempotency-Key` nas criações sensíveis.

## Consequências

Previsível para quem integra e testável de forma sistemática.

## Alternativas consideradas

GraphQL (descartado: requisito explícito de API RESTful).
