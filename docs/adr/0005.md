# ADR 0005: Autenticação com token curto e refresh rotativo em cookie

* **Status:** aceita
* **Data:** 03/10/2026

## Contexto

O protótipo guarda um JWT de 1 hora no `localStorage`, exposto a XSS, e desloga o usuário quando expira.

## Decisão

Token de acesso JWT de 15 minutos em memória; refresh token opaco, rotativo, guardado como hash, em cookie `HttpOnly; Secure; SameSite=Strict` restrito a `/api/v1/auth`. Senhas com Argon2id. Papéis `ADMIN`, `MANAGER`, `EMPLOYEE`, `CLIENT` com permissões declaradas por rota a partir da matriz em `packages/contracts`.

## Consequências

Sessão longa e segura sem derrubar o usuário; roubo de refresh detectado por reutilização. Exige API e site sob o mesmo site (subdomínios do mesmo domínio).

## Alternativas consideradas

Sessão em servidor com cookie (viável, mas a API deve servir também clientes que não são navegador); manter `localStorage` (descartado por segurança).

## Revisão de 05/10/2026

Continua precisa.
