# ADR 0006: Site com Nuxt 4, Vue 3 e Tailwind CSS v4

* **Status:** proposta
* **Data:** 03/10/2026

## Contexto

O protótipo usa Vue CLI (descontinuado) com Options API e estado global em `$root`. A loja precisa ser encontrada no Google por quem busca conserto de geladeira em Mogi Mirim, e o site precisa ser rápido no celular.

## Decisão

Nuxt 4 (Vue 3, Composition API, `<script setup lang="ts">`). Páginas públicas renderizadas no servidor com cache por rota; área logada como SPA (`ssr: false` por regra de rota). Pinia para estado, `@nuxt/image` para imagens responsivas, `@nuxt/fonts`, PWA. Tailwind CSS v4 com tokens da marca, componentes próprios sobre Reka UI (acessibilidade), ícones Lucide, FullCalendar (plugins MIT) na agenda. Cliente da API gerado da OpenAPI.

## Consequências

SEO local e LCP baixo nas páginas públicas sem abrir mão da experiência de app na área logada. Continua sendo Vue, como escolhido no projeto.

## Alternativas consideradas

Vue 3 com Vite em SPA pura (descartado: SEO fraco no catálogo); Quasar ou Vuetify (descartados: visual genérico, difícil imprimir a marca).
