# ADR 0002: TypeScript estrito em todo o código

* **Status:** aceita
* **Data:** 03/10/2026

## Contexto

O `definicao.md` escolheu JavaScript. O protótipo tem erros que um verificador de tipos teria pegado (`results.length`, variáveis globais implícitas, `constuctor`).

## Decisão

TypeScript com `strict` e `noUncheckedIndexedAccess` na API, no site e nos pacotes. Continua sendo o ecossistema JavaScript escolhido pelo projeto.

## Consequências

Tipos ponta a ponta: o esquema Zod da API gera a OpenAPI, que gera o cliente do site. Erros de contrato aparecem na compilação.

## Alternativas consideradas

JavaScript com JSDoc (descartado: verificação mais fraca e menos ferramentas).

## Revisão de 05/10/2026

Continua precisa: `strict` e `noUncheckedIndexedAccess` em `tsconfig.base.json`, herdado por todos os pacotes.
